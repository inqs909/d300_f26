Designing a Data System

Overview

In this assignment, you will act as a data systems analyst for CampusLearn, a new online learning platform. Your team must identify the types of data the platform generates, select appropriate storage technologies, and design a data pipeline that supports a weekly instructor dashboard.

Working in a group of 2-3 members. Submit one completed assignment per team.

Scenario

CampusLearn collects the following data:

  1. Student accounts and enrollments: student ID, name, email, course ID, enrollment date, and enrollment status.
  2. Activity events: JSON records created whenever a student opens a lesson, submits a quiz, or clicks a course link.
  3. Lecture recordings: video files uploaded by instructors.
  4. Course connections: relationships among courses, including prerequisites, corequisites, and recommended next courses.
  5. Login sessions: a session ID and expiration time that must be retrieved very quickly.

Each week, CampusLearn must create an instructor dashboard showing student participation, completed activities, and students who may need assistance. Data arrives continuously, but the dashboard is refreshed every Monday morning.
